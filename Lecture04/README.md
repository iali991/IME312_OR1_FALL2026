# Sensitivity Analysis and Duality: teaching notebook

Companion notebook for the lecture *Sensitivity Analysis and Duality* (Dr. Islam Ali).

## Contents
| Item | Description |
|---|---|
| `Sensitivity_Analysis_and_Duality.ipynb` | The notebook: explanations, code, figures, 9 interactive demos and PDF export |
| `data/` | Input problem files (JSON; one CSV example). Copy `99_template.json` to create your own |
| `reports/` | Sample PDF reports generated by the notebook (regenerated when you run section 10) |

## Data files
| File | Lecture use |
|---|---|
| `01_tables_chairs.json` / `.csv` | Slides 6-19: OFC and RHS changes, shadow prices, dual simplex demo |
| `02_cover_example.json` | Slide 1 (cover figure), primal simplex path |
| `03_duality_example.json` | Slides 22-23: building a dual (solved graphically) |
| `04_dakota_furniture.json` | Slides 26-38: dual of a max problem (resource prices) |
| `05_diet_problem.json` | Slides 39-47: dual of a min problem (nutrient prices) |
| `06_...`, `07_...`, `08_...` | Slides 50-56: infeasible and unbounded primal/dual cases |
| `09_practice_wyndor.json`, `10_practice_feed_mix.json` | Practice problems for students |
| `99_template.json` | Template for new models |

## Running
1. Keep the notebook next to the `data/` folder.
2. Open it in Jupyter Lab/Notebook, VS Code or Google Colab (upload the `data` folder too).
3. Run all cells. The first cell installs any missing packages: numpy, scipy, pandas, matplotlib, reportlab and ipywidgets.

The interactive demos (sliders, drop-downs, buttons) need a live kernel with `ipywidgets`. The saved notebook shows each demo's default view as a static figure.
